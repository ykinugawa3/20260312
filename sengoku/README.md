# 天下布武 Lite (Phase 1)

1560年「桶狭間前夜」から、60季節 (15年) のうちに天下統一を目指す戦国シミュレーション。
企画書の Phase 1「遊べる最小版」として、国マップ・内政・オート合戦・AI大名・武将56人を実装している。

## 起動

Windows: `sengoku_setup.bat` を一度ダブルクリックしてから、`sengoku_start.bat` をダブルクリックする
(ブラウザで http://localhost:8502 が開く)。

```bash
pip install -e '.[dev,ui]'
streamlit run sengoku_app.py
pytest tests/test_sengoku.py
```

## ルール

- 1ターン = 1季節。武将1人につき1季節に1つ命令できる。
- 命令を出し終えたら「季節を終える」を押す。AI大名の行動 → 合戦 → 収支 → 次の季節のイベントの順に進む。
- 「未行動の武将を委任」を押すと、残りの武将の命令を AI が決める。

| 命令 | 効果 | 費用 |
|------|------|------|
| 開墾 | 農業 +(10 + 政治×0.4 + 0〜10) | 金 30 |
| 商業 | 商業 +(10 + 政治×0.4 + 0〜10) | 金 30 |
| 築城 | 城の防御 +(10 + 統率×0.4 + 0〜10)、上限 1000 | 金 30 |
| 徴兵 | 兵 +(200 + 政治×4)。国の兵の上限は 農業×8 | 金 = 兵÷8 |
| 出陣 | 隣国へ攻め込む (100人以上)。合戦は季節の終わり | 兵糧 = 兵÷10 |
| 移動 | 武将が兵を連れて隣の自国へ移る | なし |
| 輸送 | 武将は残り、兵だけを隣の自国へ送る | なし |

- **収入**: 毎季節、金 += 商業の合計÷4。秋に兵糧 += 農業の合計。
- **兵糧の消費**: 毎季節、兵40人につき1。尽きると兵の1割が逃げる。
- **災害**: 夏・秋に、まれに風水害で国の農業が1割減る。
- **冬**: 雪国 (北陸・飛騨・奥羽・佐渡) から/への出陣はできない。
- **合戦**: 戦力 = 兵 × (1 + 統率/100) × 士気 (±15%)、守備側は × (1 + 城の防御/1000)。
  数ラウンドの消耗戦で、攻撃側は兵が40%を切ると退却、守備側は25%を切ると落城する。
  守備側の統率は国にいる武将の最高値 (武将がいなければ 40)。
- **落城**: 守備側の武将は隣の自国へ退く。逃げ場がなければ捕らえられ、半分は仕官、残りは浪人になる。
  当主が討たれると、統率+政治の高い武将が家督を継ぐ。国も武将も失った家は滅亡する。
- **勝利**: 全65か国を支配する。60季節を終えた時点で最大勢力なら判定勝ち。

## AI大名

`sengoku/ai.py` のルールベース。前線の国では「(送る兵 × 統率補正) ÷ 守備側の戦力」が
`2.0 - 好戦度` 以上の隣国があれば兵の8割で攻め込む。内地の国は兵と武将を前線へ送り、
残りの武将は前線なら徴兵・築城、内地なら開墾・商業のうち低い方を行う。

## 構成

| ファイル | 役割 |
|----------|------|
| `sengoku/data.py` | 国 (65か国・石高・隣接)、大名家、武将のデータ |
| `sengoku/engine.py` | ゲームの状態・命令・ターン進行 |
| `sengoku/battle.py` | オート合戦 |
| `sengoku/ai.py` | AI大名 |
| `sengoku_app.py` | Streamlit の画面 |
| `tests/test_sengoku.py` | テスト (地図の整合性・命令・合戦・60季節の通しプレイ) |

乱数は `Game(seed=...)` で固定でき、同じシードなら同じ展開になる。
