# Barrel Tower

An homage to a classic arcade game: dodge the barrels the giant ape rolls down and climb the steel girders to the top.
It is a single HTML file with no dependencies, so just open `index.html` in a browser to play.

- Controls: ← → move / ↑ ↓ ladders / Space jump & start / P pause / M sound on/off
- Smartphone: play with the on-screen buttons
- Score: jump a barrel 100 / smash a barrel with the hammer 300 / fireball 500 / bonus for reaching the top
