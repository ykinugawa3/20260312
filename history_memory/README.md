# 歴史神経衰弱

トランプの代わりに「年号」の札と「できごと」の札を使う神経衰弱です。
`index.html` をブラウザで開くだけで遊べます (インストール不要)。

- 年号の札 (黄色) と、その年のできごとの札 (緑) をめくってそろえると 1 組獲得
- 出題範囲: 日本史 / 世界史 / 両方
- 組数: 6〜12 組
- 1 人プレイ (回数と時間を記録) または 2 人対戦 (そろえたら続けてめくれる)
- クリア後に、出題されたできごとを年代順の年表で確認できる

問題を増やすときは `index.html` の `EVENTS` 配列に `{ year, text, cat }` を追加します
(`cat` は `"japan"` か `"world"`)。同じ年号のできごとは 1 ゲームに 1 つだけ出題されます。
