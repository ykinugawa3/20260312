# マクロ開発 仕様書ウィザード（Excel VBA）

質問に順番に答えていくと、マクロ開発の仕様書ができあがる Excel マクロ。
全 15 ステップ・約 60 項目（基本情報 → 概要・目的 → 動作環境 → 入力 → 処理 → 出力 → 画面 → エラー処理 →
ログ → 非機能要件 → 規約 → テスト → 運用 → スケジュール → 前提・未決事項）。

## 導入（Windows の Excel）

1. このフォルダの **`SpecWizard.bas`** をダウンロードする
   （GitHub ではファイルを開いて「Download raw file」。画面上は文字化けして見えるが、Shift-JIS なので問題ない）
2. Excel で新しいブックを開き、`Alt + F11` で VBE を開く
3. メニュー「ファイル」→「ファイルのインポート」で `SpecWizard.bas` を選ぶ
4. ブックを **Excel マクロ有効ブック（.xlsm）** で保存する
5. `Alt + F8` →「SpecWizard_Start」→「実行」

初回は「ウィザード」「設問」「回答（非表示）」シートが自動で作られる。

> `src/SpecWizard.bas` は閲覧用の UTF-8 版。これを取り込むと日本語が文字化けするので、取り込むのは
> フォルダ直下の `SpecWizard.bas` の方。

## 使い方

「ウィザード」シートの黄色いセルに入力し、上部のボタンで操作する。

| ボタン | 動作 |
| --- | --- |
| ← 戻る / 次へ → | 前後のステップへ移動（最後のステップで「次へ」を押すと仕様書を作成） |
| ステップ移動 | 番号を指定して移動 |
| 入力チェック | 必須項目の未入力を一覧表示し、そのステップへ移動 |
| 仕様書を作成 | 「仕様書」シートを作る（何度でも作り直せる） |
| Markdown 出力 | 仕様書を `.md`（UTF-8）で保存 |
| PDF 出力 | 仕様書シートを A4 縦の PDF で保存 |

- 入力形式は「1行」「複数行」「選択（ドロップダウン、一覧にない値も入力可）」「日付」。
  セル内の改行は `Alt + Enter`
- 入力内容はボタンを押したときに「回答」シートへ保存される。ボタンを押さずにブックを閉じても、
  次に `SpecWizard_Start` を実行したときに画面上の入力を拾う
- 右側の「ステップ一覧」に各ステップの状態（未着手 / 必須未入力 / 済）が出る
- 未入力の必須項目は、仕様書の末尾に「未決事項（自動抽出）」として並ぶ
- 入力欄以外はシート保護されている（パスワードなし。行の高さ・列幅は変えられる）

## 質問を変える

「設問」シートを書き換えると、ウィザードの質問が変わる（コードの修正は不要）。

| 列 | 内容 |
| --- | --- |
| ステップ | 1 からの番号。同じ番号の行が 1 画面にまとまる |
| ステップ名 | 画面・仕様書の見出し |
| 項目ID | 回答の保存キー。**重複させない**（変えると以前の回答とひもづかなくなる） |
| 項目 | 質問文 |
| 入力形式 | `1行` / `複数行` / `選択` / `日付` |
| 選択肢 | `選択` のときの候補。半角カンマ区切り |
| 必須 | 何か入っていれば必須 |
| 入力例・ヒント | 入力欄の右に表示 |

## そのほかのマクロ（`Alt + F8` から実行）

| マクロ | 動作 |
| --- | --- |
| `SpecWizard_ClearAnswers` | 回答をすべて消す |
| `SpecWizard_RestoreDefaultQuestions` | 「設問」シートを既定の内容に戻す（回答は残る） |
| `SpecWizard_RebuildScreen` | ウィザード画面を作り直す（ボタンを消してしまったときなど。回答は残る） |

## 動作環境・制限

- Windows の Excel 2016 以降 / Microsoft 365（32bit・64bit とも。Windows API は使っていない）
- 外部ライブラリの参照設定は不要
- Mac の Excel でも動く想定だが、Markdown は UTF-8 ではなく OS 既定の文字コードで保存される
- モジュールは仕様書を作るブック自体に取り込むこと（個人用マクロブックに入れると、そちらにシートが作られる）

## 開発者向け

- 編集するのは `src/SpecWizard.bas`（UTF-8）。編集後に
  `python macro/spec_wizard/tools/build_bas.py` で取り込み用の `SpecWizard.bas`（Shift-JIS / CRLF）を作り直す。
  両者がずれていると `tests/test_spec_wizard.py` が失敗する
- `python3 macro/spec_wizard/tools/smoke_test_libreoffice.py` で、LibreOffice の VBA 互換モードを使った
  簡易テストができる（画面遷移・回答保存・仕様書シート・Markdown を確認）。図形ボタンや PDF 出力は
  LibreOffice では確認できないので、最終確認は Excel で行う
