# ドットカート グランプリ

スーパーファミコン時代のカートレースをオマージュした、ブラウザで遊べる擬似3D（モード7風）レースゲームです。
`index.html` 1ファイルだけで動き、ビルドや外部ライブラリは要りません。

## 遊び方

`kart/index.html` をブラウザで開くだけです（スマホはタッチ操作に対応）。

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| アクセル | ↑ / W | A / RT |
| ブレーキ・バック | ↓ / S | B |
| ハンドル | ← → / A D | 左スティック / 十字キー |
| ジャンプ・ドリフト | Space / Shift | RB |
| アイテム | X / Z / E | X / LB |
| ポーズ | Esc / P | START |
| 音のON/OFF | M | |

- ジャンプしながら曲がるとドリフト。青→オレンジの火花が出たら離すとミニターボ
- スタート直前（GOの少し前）にアクセルでロケットスタート。早すぎるとエンスト
- コインを集めるほど最高速が少し上がる（最大10枚）

## 内容

- モード: グランプリ（4コースの合計ポイント 9-6-3-1）/ フリーラン（ベストラップ記録あり）
- クラス: 50cc / 100cc / 150cc
- ドライバー8人（軽量級・バランス・重量級・テクニック）
- コース4つ: クローバー サーキット / サンセット デザート / フロスト レイク（氷で滑る）/ スターライト ロード（落下あり）
- アイテム: バナナ、みどりこうら、あかこうら（追尾）、ダッシュキノコ、スター
- ダッシュ板、アイテムボックス、コイン、CPU対戦（7台）、オリジナルBGM・効果音
